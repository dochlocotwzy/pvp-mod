# Classic bear trap model

Low-profile vanilla cuboid item model for Minecraft 1.21.11. Footprint: 1x1 block; visible height: about 4/16 block. Includes a small custom 16x16 pixel texture. This model resource is for the item (inventory/hand). The current `TrapEntityRenderer` is intentionally empty, so the placed trap in the world still needs a renderer implementation before this asset is visible there.
